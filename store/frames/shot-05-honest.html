What the number
actually is.

MemTab reads performance.memory — the only per-page memory figure a Chrome extension can get. It is the JavaScript heap of the renderer serving a site.

It is not the tab's total memory.
Images, the DOM and the compositor are excluded. Real usage is usually 2–4× higher.
Tabs on the same site share one reading.
Chrome gives them one renderer process, so they move together.
Background tabs update slowly.
Chrome throttles hidden tabs, so their colour can be a few minutes old.

Best used as a leak detector for the tab you're on. For triaging forty background tabs, Chrome's Task Manager reads the real figure — MemTab doesn't try to replace it.
