    What MemTab measures

    The only per-page memory figure an extension can read on the stable channel is performance.memory. It reports the V8 JavaScript heap for the renderer process serving the page. Three consequences worth knowing:

    • It is not the tab's total memory. It excludes the DOM, images, decoded bitmaps, canvas and the compositor — usually most of what a tab really costs. The browser's own Task Manager (Shift+Esc) shows the real figure.
    • Tabs on the same site share it. Same-site tabs are put in one renderer process, and they share one JavaScript heap — so ten GitHub tabs will all show the same reading, and all turn red together if one of them leaks.
    • Background tabs update slowly. Hidden tabs are throttled to about one timer fire per minute, and may freeze or discard them entirely. A background tab's colour can be minutes old.

    MemTab is most useful as a leak detector for the tab you are actually on: watch it walk from healthy to high over a session and you have found something. It is not a substitute for the Task Manager when triaging which of forty tabs to close.
